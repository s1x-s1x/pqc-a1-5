## 需要统一的事实

- SM3 实例的标准类别不从 SHA2/SHAKE 参数类别继承；n=16 的截断长度不独立构成 NIST 类别认证。
- q=2^24 时 FORS 暴露概率项指数约 128.6297，仅是该单项概率，不是整体 EUF-CMA 或量子安全位数。超限曲线是分析对象，不是允许超用；严格签名预算保持上限。
- 当前 ACVP SHA2-128s/128f 纳入 208 个操作检查；1248 是十二参数的合计，不用于此范围。外部 xous 128-24 与 SM3 独立向量分别记录来源。
- 当前整树 FORS 的 PRF/F/H/T 结构调用合计 `3*k*2^a+1=301,989,889`。旧 301,989,732 属不同参考路径口径，不与整树实现混算。
- 当前线程拆分合并总 H 仍为 `2^z-1`，不存在可统一加到并行记录的固定约 440 差值。WOTS 链步依实际消息而变，理论/observed、原语/压缩分别列字段。
- TSC ticks 经频率换算得到时间；核心 cycles 需硬件计数器证据，缺测时留空。调用数下降不等于同幅度时延下降。
- 577 个 case 是四份 CPU/CUDA 计划配置总数，不代表正式采样已经执行。工程日志运行时长不作为作品性能结果。
- 原修复版 CPU 3471/3471、CUDA 1789/1789、功能 11 项等数值属于其绑定版本，新的接口/预算/续跑修订需新验收记录；旧通过数不挪给新源码。
- 替代链约束证书字段，在线持有证明、Finished 与完整会话认证各有独立条件。完整模型十次超时只记超时未完成，不填预期结果码。
