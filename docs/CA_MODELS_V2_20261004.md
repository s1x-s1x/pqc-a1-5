v2 把服务端实际发送对象组织成五字段：`CONCAT(serverHello, certificateTranscript, onlineSignature, onlineAltSignature, serverFinished)`。Client 实际 SPLIT 完整对象及 serverHello、证书、在线公钥；ASSERT 接受的证书一致性和本地 identity/use/validity/algorithms，重验拆出的 CA 签名；签名验证、DH、KEM、Finished 和 transcript 全部使用从收到对象获得的字段。

保留单个签名字节的 SignatureOrigin，另增加完整 flight 的 SessionAuth；Binding、SignatureOrigin、SessionAuth、Fresh、Secret 五条查询都以客户端发出 appRecord 为接受前提。Verifpal 要求来源查询对象显式接收，故 onlineSignature 以 CV 字段的投影观察随完整对象传递，并 ASSERT 等于 SPLIT 出的签名。它不是新协议字节统计，不应把该符号投影计入 TLS 开销。
