# 当前项目安全假设与保证边界

2026-10-04。项目实现和工程验收与完整计算安全证明分别记录。

SM3实例采用实验参数/OID。SP800-230草案128-24的单密钥总签名量上限为2^24，
包含共享该密钥的全部设备；软件账本只约束使用它的入口。直接C调用、另一份数据库
或恢复备份需要操作者另行对账。预约先收费，失败或崩溃保留消耗，迁移不重置用量。
UUID是身份绑定，receipt是对账证据，二者不提供数据库副本抗回滚硬件保证。

签名候选在库内生成；启用自验时，REF恢复成功后才复制。关闭自验时仍保持候选隔离。
候选生成/自验失败返回长度0并清除对应输出。显式擦除覆盖纳入测试的CPU秘密工作区、候选及CUDA seed/host job生命周期。
这些检查不等于物理侧信道测试，也不保证操作系统、编译器/设备内部副本全部清除。
调用者独立拥有ctx，突变和同ctx并发调用须遵守SPEC。

缓存只保存公共节点，核验尺寸、参数、公钥、摘要和根。使用同一个打开fd做尺寸前检
与提交前状态复核，损坏/追加/截断失败保留旧cache。摘要用于损坏检测，根与PK绑定
用于避免替换输入被采用；它不是用秘密MAC构造的缓存认证协议。

替代链绑定身份、在线公钥、算法、用途与期限，严格策略拒绝剥离/降级。128-24用于
离线CA，在线双证明单独采用Falcon/ML-DSA等。经典CA泄露和经典在线密钥泄露是两个
不同场景：替代链的证书绑定作用不得外推成独立完整在线认证保证。

TLS使用私有harness和测试OID/码点，生产吊销/CRL/OCSP、复杂CA治理、HRR、PSK/
恢复/0-RTT、KeyUpdate、标准alerts等功能仍按原型能力限制披露。根锚与策略本地可信，
测试私钥仅供夹具复现。形式化结果受会话边界和理想原语假设限制；首次失败日志保留。
FORS概率项指数不等于完整EUF-CMA/量子安全位数或SM3标准类别。

正式性能、能耗、网络条件和物理侧信道测量均未开展；报告后续只采用绑定当前源码的
最终记录，旧数值与新结果分版保留。
