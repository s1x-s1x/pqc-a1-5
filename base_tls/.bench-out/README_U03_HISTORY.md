# 测量记录：版本与适用范围

本目录有两段历史，读数值前先看时间戳：

1. **修复前（原始 v6）**：XMSS 公钥为 32 字节根、链步密钥为全局常量。这些数值属于修复前版本，不能作为 U-03 修复后的实验结果。
2. **并入 U-03 补丁后（本修订）**：`tools/verify_all.ps1` 已在合并后的树上重新运行，`handshake.*`、`primitives.*`、`shaped.*`、`tcp.*` 全部是本次重新生成的测量，可作为本修订的数据；XMSS 公钥此时为 `root || public_seed`（64 字节），方案编号 `0xFE00 + height`。

`.bench-u03/` 是补丁作者在合并前、基于其本地副本的测量记录，保留作对照与溯源；需要引用"谁的机器、哪棵树"时用它。其他原文报告中的旧数据同样应标明版本后使用。
